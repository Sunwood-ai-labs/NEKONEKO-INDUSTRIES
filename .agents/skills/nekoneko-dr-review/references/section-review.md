# 断面レビュー：図から設計判断まで

ネコネコインダストリーのDR定義v2で使う手順です。断面図は証拠の一つで、図を作ったことは設計の妥当性を判断したことではありません。対象に応じて必要な断面を選び、固定の枚数・一定間隔の走査を全模型へ課しません。

## DR0：見る部位と目的を決める

要求、既知の失敗、変更箇所に対応する確認表を作ります。例えば中空のバスなら、窓中央と柱、屋根との付け根、補強の始終端、前後端、固定輪の接合、内部レール・突起・開口を候補にします。形状の変化点とその直前・直後を含め、必要なら長手・幅・高さ方向を組み合わせます。

検証片に含まれる部位と含まれない部位を明記します。検証片の結果を、含まれない車輪・端部・下側レールや、全体で閉じ込められる支持へ自動継承しません。

## DR1：実CADを見て、機能から判断する

1. 保存した版を再読込し、切断面の座標系、軸・位置、切出し範囲、必要に応じて曲線の近似条件を記録します。CADの断面とSTL・スライスの断面を混同しません。
2. 出力した図を実際に開きます。穴・空洞・材料の輪郭を識別でき、縮尺と切断位置が読み取れることを確認します。所見の位置を番号や矢印で示します。
3. 各部位で、要求される機能、肉厚の変化、荷重を伝える接続、鋭い角・細い縁・段差、不要な棚や残骸、袋小路、開口と工具の空間を判断します。「形が変」にとどめず、想定する問題と確認方法を書きます。必要な支持部と機能不明の形状を区別し、内部を一括で削除しません。
4. 判断に必要な寸法・断面・接続を測り、観察した事実、原因の仮説、未確認事項を分けます。各所見を「根拠を示して残す／修正する／測定・解析・経路確認へ戻す／実物検証で確認する」のいずれかへ対応づけます。許容差や安全基準を勝手に設定しません。
5. 修正後に同じ位置を比較し、変更の境界と隣接部も見ます。肉を足したことで窓が狭くなる、突起を削ったことで車輪の接続を失う、という別の問題を確認します。修正済みと検証済みは別に記録します。
6. 保存CADの再読込と、実際に出力するメッシュの閉鎖性・接続を確認します。変換後に不成立ならその候補を合格にせず、失敗を残して修正します。ただし、閉じたメッシュだけでは機能・強度・除去性は合格にしません。

### 測定・切断の取り違えを防ぐ

- 切出し箱の端で切れた隣の柱の幅を、柱全体の最小肉厚にしません。測定方向の幅、面への法線方向の肉厚、輪郭の包絡寸法を区別します。
- FreeCADなどで曲面の制御点を含む境界箱が出る場合、適切な境界箱、断面座標、実メッシュ頂点と照合します。通常の境界箱だけで異常な外形と判定しません。
- 共通体積や共通面積が0だっただけで、接続していないとは判定しません。共有境界をその演算が返すか、トポロジーと他の観察を確かめます。測定が成立しなければ未確認とします。
- 境界面に一致する切断や、極めて近い切断で輪郭が途切れたら、隣接位置、再読込CAD、実メッシュと照合します。数値処理の問題とも実体の欠陥とも即断せず、未解決を残します。

## DR2：断面と解析条件を照合する

解析が必要と選定された部位について、DR1の重要断面と解析モデル・荷重経路を対応づけます。柱や輪の根元、接合面、拘束面・荷重面が意図した全幅・面積を含むか確認します。検証片の切断で隣の部材の拘束や荷重分担を失う影響も記録します。

CADの外形厚を、そのまま中実の印刷断面と仮定しません。実造形の壁数、充填、積層方向と解析の材料・中実性を照合します。簡単な梁計算、均質な弾性FEM、実物の剥離力・破断試験を別々に扱い、必要な収束・感度確認と限界を残します。全ての模型にFEMを一律で要求する手順ではありません。

## DR3：実経路と支持の取り出しを判断する

1. DR1の重要断面を造形座標・対象層へ対応づけ、最終3MF内の実G-codeと材料番号を確認します。外周、隙間充填、疎・密な充填、橋渡し、支持本体、専用材の界面を区別して図示します。
2. 全層を重ねた投影に加え、接触が始まる・終わる層、根元・窓縁・段差など判断が変わる層を選びます。投影で重なる線が同じ高さで接触するとは限りません。経路の移動数を接触面積・剥離力と扱いません。
3. 支持の接触位置、分割と外す順序、工具の進入口、取り出し方向と出口、枠に伝わる力を部位ごとに判断します。工具が届く根拠や、引っ掛かり・閉じ込めの懸念を記録します。機械や工具の未確認寸法を仮定で合格にしません。
4. 形状・姿勢・設定・材料が変われば、影響する経路を再スライスして見直します。旧版のスライス、FEM、除去結果を新しい版へ移しません。

データ上の除去方法は予測です。専用材の指定、警告なし、preflightの成功だけでは現物除去を実証できません。検証片の実物除去条件と、機械記録・人間の観察を別欄に残します。

## DR4：所見を閉じる

所見IDごとに判断・処置・再確認を照合します。改修前後の図、対象ファイルとSHA-256、未確認の範囲を対応づけます。「確認した断面数」「不具合候補の数」「修正した件数」「改善を実証した件数」を混同しません。未解決の必須確認は不通過のままにします。
